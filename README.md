# Pizza Order SPA

A multi-page pizza ordering application with a custom order form, topping selection, order summary, and backend integration — built with React and React Router.

## Live Demo

[pizza-order-spa on Vercel](https://pizza-spa-eta.vercel.app)

## Features

- Step-by-step order flow (menu → customize → confirm)
- Dynamic topping selection with price calculation
- Form validation with user feedback
- Order success page with order details
- Unit & integration tests with React Testing Library

## Tech Stack

| Category | Technologies |
|----------|-------------|
| Framework | React 19 + Vite |
| Routing | React Router DOM v7 |
| HTTP | Axios |
| Notifications | React Toastify |
| Testing | React Testing Library + Jest |

## Getting Started

```bash
npm install
npm run dev
```

Run tests:

```bash
npm test
```
